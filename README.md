# たびのあと — 旅からつくる、小さな世界。

日本地図で行った都道府県を選び、その県のかたちの中に建物や自然を置いて育てる箱庭です。写真のアップロードはありません。

**開く:** https://tarozzz127.github.io/study/

## あそびかた

1. 日本地図の都道府県をタップして拡大します。小さな県は上の「都道府県を選ぶ」一覧からも選べます。
2. 「つくる」で家・カフェ・神社・タワー・山・森・水辺・キャンプからパーツを選び、県の輪郭の内側をタップ。場所の名前・訪れた日・任意のメモを入力します。
3. 「この場所に置く」で完成。1か所100pt、5か所ごとにレベルアップします。全パーツを最初から使えます。
4. 置いたパーツや「旅のきろく」をタップすると、思い出を見返したり、編集・移動・削除したりできます。
5. 移動では県の内側の空いている場所を選びます。移動中に県を選び直せば、別の県へ移せます。直前の変更は通知の「戻す」で取り消せます。

47都道府県の輪郭を使ったイラスト地図です（測量・ナビ用ではなく、一部の小さな島は省略）。初めは白い日本地図で、思い出を置いた県が淡い緑になります。近所の公園でも、遠くの旅先でも大丈夫。iPadの縦・横画面とスマートフォンに対応しています。拡大ボタンで地図を大きくし、指でスクロールできます。「日本全体」で全国へ戻ります。キーボードでも県を選び、県の箱庭にフォーカスして矢印キーとEnterで配置できます。

前の四角い箱庭の思い出は消しません。「旅のきろく」に残り、「移動」から行った県を選んで置き直せます。県を勝手に推測して割り当てることはありません。以前の箱庭バックアップ（version 1）も読み込めます。新しい書き出しは県の情報を含むversion 2です。

東京や沖縄など離島が遠くにある都県は、本土・本島から表示します。「離島を含めて県全体を表示」で島々も見られます。

## 保存とバックアップ

- この端末・このブラウザのIndexedDBに自動保存します。アカウント・サーバー保存・自動同期はありません。
- 再読み込み後も残りますが、ブラウザのデータ削除・自動整理・プライベートブラウズの終了などで消える場合があります。
- 右上の設定からJSONファイルに保存・読み込みできます。読み込み時には**今の箱庭を置き換える**確認が出ます。先にバックアップを保存してください。
- 前の写真つき旅ログのデータベースは変更も削除もしません。既存の記録がある場合、設定から従来形式で書き出せます。旧旅ログと箱庭のファイル形式は異なり、自動変換はしません。
- 写真・地図・位置情報のAPIは使いません。県の輪郭データはアプリに同梱しています。フォントだけGoogle Fontsから取得し、取得できない場合は端末のフォントを使います。
- 起動・再読み込みにはネット接続が必要です。読み込み済みの画面は接続が切れても閲覧・編集できます。URLが変わると保存先も変わるため、同じ公開URLを使い続けてください。

## 開発

Node.js 24 LTS（nvmなら `nvm use`）を使います。

```sh
npm ci
npm run dev
npm test
npm run build
npm start
```

`npm start` はビルド済みの画面をポート3000で表示します。mainにpushするとGitHub Actionsが同じGitHub Pages URLへ公開します。

### 主なファイル

- `src/App.jsx`: カタログ・思い出の入力・表示・バックアップ
- `src/DioramaMap.jsx`: タップ・キーボードで操作できる箱庭と拡大
- `src/PieceArt.jsx`: 外部画像に依存しない立体風SVGパーツ
- `src/lib/diorama.js`: 箱庭の保存とバックアップの検証
- `src/lib/prefectures.js`: 都道府県の輪郭・県の内側の配置判定
- `src/lib/japan-map.js`: 47都道府県の輪郭データ（出典とライセンスは `MAP-LICENSE.md`）
- `src/lib/storage.js`: 旧旅ログの読み出し・従来形式の互換処理
- `src/styles.css`: iPad・スマートフォン対応

使用技術: React / Vite / Lucide / SVG / IndexedDB
