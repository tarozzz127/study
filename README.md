# たびのあと — 旅からつくる、小さな世界。

日本地図で行った都道府県を選び、その県のかたちの中に建物や自然を置いて育てる箱庭です。写真のアップロードはありません。

**開く:** https://tarozzz127.github.io/study/

## あそびかた

**かんたんに置く:** 地図の上で「東京タワー」「富士山」など場所の名前を検索し、候補をタップ。建物・自然を自動で選び、検索結果の緯度・経度と同じ位置へ保存します。保存したパーツをタップして「編集・サイズ」すると、日付・名前・メモ・パーツ・見た目・サイズを変えられます。同じ候補は重複せず、既存の思い出が開きます。手動で移動すると検索位置との結び付きが外れます。

**好きな位置に置く:**

1. 日本地図の都道府県をタップして拡大します。小さな県は上の「都道府県を選ぶ」一覧からも選べます。
2. 「つくる」で家・カフェ・神社・タワー・お城・宿・橋・駅・山・森・水辺・キャンプ・滝・花畑の14種類からパーツと見た目を選び、県の輪郭の内側をタップ。場所の名前・訪れた日・任意のメモを入力します。
3. 「この場所に置く」で完成。1か所100pt、5か所ごとにレベルアップします。全パーツを最初から使えます。
4. 置いたパーツや「旅のきろく」をタップすると、思い出を見返したり、編集・移動・削除したりできます。
5. 移動では県の内側の空いている場所を選びます。移動中に県を選び直せば、別の県へ移せます。直前の変更は通知の「戻す」で取り消せます。

47都道府県の輪郭と緯度・経度が対応した地図です（測量・ナビ用ではなく、一部の小さな島は省略）。青い海と白い陸地を分け、思い出を置いた県は緑になります。近所の公園でも、遠くの旅先でも大丈夫。iPadの縦・横画面とスマートフォンに対応しています。拡大ボタンで地図を大きくし、指でスクロールできます。「日本全体」で全国へ戻ります。キーボードでも県を選び、県の箱庭にフォーカスして矢印キーとEnterで配置できます。

前の四角い箱庭の思い出は消しません。「旅のきろく」に残り、「移動」から行った県を選んで置き直せます。県を勝手に推測して割り当てることはありません。以前の箱庭バックアップ（version 1・2・3）も読み込めます。旧イラスト上で手動配置した記録は元の座標を変更せず、新地図上の相対位置で表示します（海に出る場合は表示のみ陸地に寄せます）。新しい書き出しは検索の緯度・経度・座標形式・見た目・サイズを含むversion 4です。

東京や沖縄など離島が遠くにある都県は、本土・本島から表示します。「離島を含めて県全体を表示」で島々も見られます。

## 見た目とサイズを選ぶ

各パーツに3つずつ、全42デザインを用意しています。カタログでパーツを選ぶと見た目の候補が表示されます。配置時も、置いた後の「編集・サイズ」でも変更できます。スライダーで25〜300%を1%刻みで自由に調整し、プレビューを見ながら選べます。＋／−ボタンと100%に戻すボタンも使えます。「変更を保存」するまで元の記録は変わらず、閉じると変更を取り消します。地図全体のズームとは独立して、パーツごとに大きさを保存します。移動・再読み込み・バックアップでも見た目とサイズを保ち、古い記録は従来の見た目・100%で表示します。

### 2本指で大きさを変える

- 地図の上で2本指を広げると拡大、つまむと縮小できます（100〜300%）。指の間の場所を中心に拡大し、1本指で地図を動かせます。従来の＋・−・全体表示ボタンも使えます。
- 置いたパーツをタップ →「地図上でピンチしてサイズ調整」を選ぶと、地図上の2本指操作でそのパーツだけを25〜300%に調整できます。「サイズを保存」で確定し、「キャンセル」で元に戻ります。パーツの位置や思い出は変わりません。
- 「編集・サイズ」のプレビューの絵もピンチできます。スライダーや＋・−ボタンも引き続き使えます。編集を保存するまでは記録を書き換えません。
- 地図とプレビューの中だけでアプリのピンチ操作が働きます。その外側ではブラウザの拡大やページのスクロールをそのまま使えます。

## 保存とバックアップ

- この端末・このブラウザのIndexedDBに自動保存します。アカウント・サーバー保存・自動同期はありません。
- 再読み込み後も残りますが、ブラウザのデータ削除・自動整理・プライベートブラウズの終了などで消える場合があります。
- 右上の設定からJSONファイルに保存・読み込みできます。読み込み時には**今の箱庭を置き換える**確認が出ます。先にバックアップを保存してください。
- 前の写真つき旅ログのデータベースは変更も削除もしません。既存の記録がある場合、設定から従来形式で書き出せます。旧旅ログと箱庭のファイル形式は異なり、自動変換はしません。
- 県の輪郭データはアプリに同梱し、タイル地図・現在地取得・写真APIは使いません。検索を押した時だけ、入力した場所名をPhoton（OpenStreetMapデータ）へ送ります。APIキーは不要です。検索には通信が必要で、見つからない場所は手動で置けます。フォントはGoogle Fontsから取得し、取得できない場合は端末のフォントを使います。
- 起動・再読み込みにはネット接続が必要です。読み込み済みの画面は接続が切れても閲覧・編集できます。URLが変わると保存先も変わるため、同じ公開URLを使い続けてください。

## 開発

Node.js 24 LTS（nvmなら `nvm use`）を使います。

```sh
npm ci
npm run dev
npm test
npm run build
npm start
```

`npm start` はビルド済みの画面をポート3000で表示します。mainにpushするとGitHub Actionsが同じGitHub Pages URLへ公開します。

### 主なファイル

- `src/App.jsx`: カタログ・思い出の入力・表示・バックアップ
- `src/DioramaMap.jsx`: タップ・キーボードで操作できる箱庭と拡大
- `src/PlaceSearch.jsx` / `src/lib/place-search.js`: 場所検索・候補の分類・自動配置
- `src/PieceOptions.jsx`: 見た目の候補・サイズ調整とプレビュー
- `src/PieceArt.jsx`: 外部画像に依存しない立体風SVGパーツ
- `src/lib/diorama.js`: 箱庭の保存とバックアップの検証
- `src/lib/prefectures.js`: 都道府県の輪郭・県の内側の配置判定
- `src/lib/geographic-map.js`: 緯度・経度に対応したNatural Earthの県の輪郭（出典とライセンスは `MAP-LICENSE.md`）
- `src/lib/japan-map.js`: 旧イラスト座標の検証・互換用データ
- `src/lib/storage.js`: 旧旅ログの読み出し・従来形式の互換処理
- `src/styles.css`: iPad・スマートフォン対応

使用技術: React / Vite / Lucide / SVG / IndexedDB
