## たびのあと — 旅を地図に残すアプリ

iPadでも使える、写真とひとことの旅ログです。最初は記録のない地図から始まります。

### 使い方

1. 「場所を探す」で背景の地図を表示し、指で動かして訪れた場所をタップします。
2. 場所の名前と日付、写真、短いメモを入れます（写真とメモは任意です）。
3. 建物か山のマークを選び、「地図に残す」を押します。
4. 地図のマークや左側の記録をタップすると、見返す・編集・削除ができます。

「自分の地図」は、建物と山だけが増えていくまっしろな地図です。保存するとこの表示に戻り、今の位置とズームを保ったまま思い出が置かれます。「場所を探す」との切り替えで位置や記録は変わりません。再読み込み時と「地図全体を表示」では、保存した場所をまとめて見渡せます。

マークが重なった場所をタップすると、場所名・日付・マークの一覧から見たい思い出を選べます。同じ場所にある複数の記録も、地図を拡大せずに選べます。

キーボードでは地図をフォーカスして矢印で移動し、「地図の中央に記録」で追加できます。

### データについて

- 写真・メモ・位置は、この端末のこのブラウザのIndexedDBに保存します。アカウント、サーバー保存、自動同期はありません。
- ページを再読み込みしても記録は残りますが、ブラウザのデータを削除すると消えます。プライベートブラウズの終了やストレージの自動整理でも失われる場合があります。
- 「使い方」から写真を含むJSONバックアップの保存・読み込みができます。別端末への移行にも使えます。読み込みは既存の記録を残し、同じIDの記録だけを更新します。
- 写真は端末内で長辺1600px以下のJPEGに縮小します。20MBまでのJPEG・PNG・WebPが使えます。HEICはブラウザが対応する場合のみ使え、開けない場合はJPEGなどへの変換を案内します。
- 地図の表示には外部のOpenStreetMapタイルとインターネット接続が必要です。地図の表示位置と接続情報がタイル提供元に送られます。写真とメモは送信しません。文字フォントはGoogle Fontsから取得し、取得できない場合はシステムフォントを使います。
- 現在地はボタンを押してブラウザの位置情報を許可した時だけ取得します。

### 開発する

Node.js 24 LTSとnpmを使います。nvmがある場合は `nvm use` で切り替えられます。

```sh
npm install
npm run dev
```

表示されたアドレスをブラウザで開きます。

```sh
npm test        # 保存・更新・削除・バックアップのテスト
npm run build  # 公開用ファイルをdistに生成
npm start      # 公開用ファイルをポート3000で確認
```

`npm start` は先に `npm run build` が必要です。公開時はHTTPSと同一のURLを維持してください。保存した記録はURL（origin）ごとに別になります。

### ファイルの役割

- `src/App.jsx`: 記録の一覧と画面全体の状態
- `src/TravelMap.jsx`: Leafletの地図とマーク
- `src/MemoryDialog.jsx`: 写真とメモの入力・表示
- `src/MarkerArt.jsx`: 建物と山のイラスト
- `src/lib/storage.js`: 端末内の保存とバックアップ
- `src/lib/photo.js`: 写真の縮小
- `src/styles.css`: iPad・スマートフォン向けのレイアウト
